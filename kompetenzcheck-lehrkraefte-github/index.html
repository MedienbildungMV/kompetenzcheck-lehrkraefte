Worum geht es?

Dieser Kompetenzcheck unterstützt Sie dabei, Ihre professionelle digitale Handlungskompetenz im Unterricht zu reflektieren. Er ist keine Prüfung, keine Zertifizierung und keine Bewertung.

Im Mittelpunkt stehen konkrete professionelle Handlungen: Was setzen Sie bereits sicher ein? Wo möchten Sie sich weiterentwickeln? Welche Rahmenbedingungen erschweren die Umsetzung?

Wichtig: Die Antworten werden ausschließlich in Ihrem Browser verarbeitet. Es werden keine Ergebnisse automatisch an eine Schule, GitHub oder andere Stellen übertragen.

Sie erhalten am Ende

✓ ein persönliches Kompetenzprofil

✓ Ihre stärksten Handlungsfelder

✓ mögliche Entwicklungsfelder

✓ Hinweise zu förderlichen Rahmenbedingungen

✓ einen konkreten nächsten Entwicklungsschritt
